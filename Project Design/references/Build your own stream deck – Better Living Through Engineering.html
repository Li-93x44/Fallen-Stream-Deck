Build your own stream deck

A stream deck is like a miniature keyboard that can be used to control your computer through hotkey assignments. This is especially useful when combined with software like OBS (Open Broadcaster Software) which acts like a virtual broadcast production control room. In this guide we’ll look at how you can build a stream deck yourself, so let’s get started!

OBS

Open Broadcaster Software is a common virtual broadcast application that manages everything (Camera, mics, scenes etc) before broadcasting your content live, recording your content, or passing it off to a video conferencing client like Zoom. The easier it is to control OBS, the less obvious it is that there is even an extra system there, this is where a stream assistant or deck comes in. There are stream decks commercially available, one of the most popular and well known is the Elgato StreamDeck. But this blog isn’t called BetterLivingThroughBuyingStuff, so lets look at what we need to do to make one ourself.

The Outline

Lets brainstorm. We need;
1. A controller to communicate with the PC.
2. Switches to act as my input devices.
3. A box to house all the component.
4. Some code to translate the physical keypresses into keystrokes

I’ll also add a port at the pack to attach a foot pedal which will give me the ability to have a hands free way to trigger push-to-talk or PTT.

1. For the controller we can use an Arduino Pro Micro ATmega32U4 which we’ll program to act like a USB keyboard. This will essentially send keystrokes to the computer when the switches are pressed, which we will map to any command we want. One interesting thing to note is that your keyboard actually has some hidden keys, keys F13-F24 to be exact. Because of this, we don’t have to worry about accidentally having two keys perform the same function confusing our computer.

2. For the switches I decided to get some Cherry MX Black keyboard switches. Cherry MX switches are arguably the best keyboard switches you can get, found in many gaming keyboards. They come in a variety of configurations, with varying activation modes, required activation forces, and RGB housings. The Black model has a linear activation and requiring a nice force to activate, and while there are holes to pass through 3mm LED, the housing is not opaque so you don’t tend to get the same RGB performance you would with an opaque switch housing. Mouser is a good electronics wholesaler to get components like this in the US, you can check out the Cherry MX Black at Mouser here. To go along with the switches I also needed some keycaps. These interestingly were the most difficult item to find, but I did find some plain black keycaps from SparkFun electronics, another great electronics resource.

3. For the box to house the components, I designed a two piece box in AutoDesk Fusion360, and then 3D printed it on my Creality Ender 3 Pro printer. I wanted to match the geometry of my existing keyboard, this is total overkill, but wasn’t really that much more work than designing a standard box.

4. Finally, the system was controlled by programming the arduino to read the switch values, and if a certain switch was pushed, it would communicate with the computer using a ‘Keyboard’ library and send the corresponding ‘F-key’ stroke, but more on the specifics on that later.

So with that, let’s get started!
